# hermes-jev-router — роутер моделей для Hermes Agent

Плагин `jev-router` для [Hermes Agent](https://hermes-agent.nousresearch.com).

Плагин сам выбирает, какой моделью Гермесу отвечать на каждое сообщение:

| Задание | Модель по подписке ChatGPT | Модель через OpenRouter |
|---|---|---|
| **лёгкое** — привет, факт, перевод, исправить опечатки, вытащить данные из текста | GPT-6 Luna | DeepSeek V4 Flash |
| **среднее** — пост, письмо, план, объяснение, совет, обычный код | GPT-6 Sol | GPT-6 Sol |
| **сложное** — найти причину сбоя, спроектировать систему, решение с деньгами/налогами/рисками, математика, большая работа с кодом | GPT-6 Astra | GPT-6 Astra |

Решает **Джев** (Jev, модель TypeSafe): он не пишет текст, а за ~0,3 секунды отвечает на пять узких вопросов о сообщении.
Одно решение стоит около $0.00006 — примерно $1.8 на 30 000 сообщений.

Под каждым ответом появляется строка, кто ответил:

```
— Ответила: GPT-6 Luna · Джев: лёгкое задание · 312 мс
```

## Насколько точно

Проверено на 241 сообщении из жизни, работы, денег, путешествий, контента, кода и учёбы, без чьей-то личной переписки.
Контрольные 120 из них писал отдельный автор, правило решения было зафиксировано до проверки.

| | Точность | Занизил уровень | из них сложное → Luna | Завысил уровень |
|---|---|---|---|---|
| jev-router | **95.8–97.5%** | 0–1 из 120 | **0** | 3–4 из 120 |
| простой роутер «один вопрос по последнему сообщению» | 65% | 24 из 120 | 0 | 18 из 120 |

(Два числа — по двум независимым разметчикам.)

Ловушки: «короткий, но сложный вопрос» — 12 из 13, «длинный текст, но простая просьба» — 11 из 12, продолжение разговора («да, делай», «спасибо, заработало») — 25 из 27.
Почти все ошибки — в безопасную сторону: лёгкое уходит в среднюю модель. Подробности — `eval/REPORT.md`.

## Установка

```bash
hermes plugins install https://github.com/HinkoK/hermes-jev-router
hermes plugins enable jev-router
```

Нужен ключ для Джева, один из двух (в `~/.hermes/.env`):

- `OPENROUTER_API_KEY` — Джев через OpenRouter ([ключ](https://openrouter.ai/settings/keys), на балансе хватит $1 на месяцы);
- `TYPESAFE_API_KEY` — напрямую в TypeSafe.

Включить: в чате Гермеса (Телеграм, Десктоп, терминал) написать `/router on`.

**Модель чата должна быть одной из трёх уровней** (например, GPT-6 Sol по подписке): роутер меняет модель только внутри того же провайдера.

## Команды

| Команда | Что делает |
|---|---|
| `/router on` | Джев выбирает уровень для каждого сообщения |
| `/router off` | роутер выключен, отвечает модель чата |
| `/router light` · `standard` · `heavy` | закрепить все сообщения за одним уровнем (синонимы: `luna`, `sol`, `astra`) |
| `/router log 10` | последние решения: уровень, модель, время |
| `/router check 10` | какая модель реально ответила (по ответу сервера) и сколько это стоило бы по API |
| `/router stats 50` | доли лёгких/средних/сложных и сравнение: сколько стоило бы, если бы всё шло на одну модель |
| `/router status` | текущие настройки |

Из терминала то же самое: `hermes jev-router on`, `hermes jev-router log 10`, а `hermes jev-router route "текст"` покажет решение Джева без ответа модели.

## Как это устроено

1. Перед каждым запросом к модели Гермес даёт плагинам поправить запрос.
2. Роутер берёт ваше последнее сообщение и до четырёх прошлых реплик разговора (чтобы понять «да, делай» или «спасибо, заработало»).
3. Джев в одном вызове отвечает на пять вопросов:
   - какой уровень нужен (выбор из трёх, с правилами и примерами для каждого);
   - сколько нужно думать (шкала: нисколько / обычно / глубоко);
   - продолжает ли сообщение прошлую задачу;
   - просит ли оно работы с проектом, файлами, командами;
   - дорого ли обойдётся незаметная ошибка (деньги, закон, здоровье, безопасность, прод).
4. Код складывает ответы (`decide` в `__init__.py`). Занизить уровень хуже, чем завысить, поэтому шкала и сигналы «дорогая ошибка» и «работа с проектом» могут только поднять уровень, а для лёгкого нужно согласие двух ответов.
5. В запросе меняется только название модели. История, инструменты, подписка — те же.

Если Джев не ответил за 4 секунды или ключа нет, отвечает модель чата. Кроны не роутятся.

## Настройки

`hermes config set plugins.entries.jev-router.settings.<ключ> <значение>`

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `models` | см. таблицу выше | свои модели: `{openai-codex: {light: gpt-5.6-luna}}` |
| `show_model` | `true` | строка «Ответила: …» под ответом |
| `log_text` | `false` | хранить в журнале первые 80 символов сообщения (иначе только длину) |
| `heavy_at` / `light_at` | `0.45` / `0.55` | пороги решения: меньше `heavy_at` — чаще сложное; больше `light_at` — реже лёгкое |
| `skip_platforms` | `[cron]` | где не роутить |
| `timeout_s` | `4` | сколько ждать Джева |

## Приватность

Текст сообщения (до 12 000 символов) и четыре прошлые реплики (по 400 символов) уходят в Джев — через OpenRouter или TypeSafe. Если это неприемлемо для какого-то чата, выключите роутер там (`/router off`). Журнал решений лежит у вас локально и по умолчанию не хранит текст сообщений.

## Особенности подписки ChatGPT (Codex)

- У подписки нет отдельного счёта по запросам, поэтому `/router check` сверяет модель по ответу сервера, а доллары считает «как если бы по API» (токены × цена той же модели на OpenRouter).
- Подписка не принимает скрытые рассуждения одной модели в запросе к другой. Когда модель в разговоре меняется, роутер убирает рассуждения прошлых ходов из запроса. На ответы это почти не влияет.

## Сколько лимита подписки тратит каждая модель

OpenAI не публикует, насколько ответ Luna дешевле для лимита, чем ответ Astra. Это можно измерить на своём аккаунте:

```bash
python3 tools/measure_limits.py --dry-run     # показать счётчик лимитов и план, ничего не тратить
python3 tools/measure_limits.py               # Luna, потом Astra
python3 tools/measure_limits.py --tiers light,standard,heavy
```

Скрипт закрепляет роутер за уровнем, шлёт один и тот же короткий запрос и после каждого перечитывает счётчик (`hermes usage`). Серия заканчивается, когда 5-часовое окно сдвинулось на 3% (или после 30 запросов). В конце он печатает, сколько процентов окна стоит один ответ каждой модели. Счётчик показывает целые проценты, поэтому результат — диапазон. Роутер после теста возвращается в прежний режим. Тест расходует примерно 4% окна на каждый уровень, запускать лучше сразу после сброса окна.

## Проверка на своём компьютере

```bash
python3 -m unittest discover -s tests          # офлайн-тесты, без сети
cd eval && python3 harness.py dev PROD --errors # точность на рабочем наборе (нужен ключ, ~$0.007)
```

Правила разметки — `eval/RUBRIC.md`, наборы — `eval/dev.jsonl` и `eval/holdout.jsonl`.
